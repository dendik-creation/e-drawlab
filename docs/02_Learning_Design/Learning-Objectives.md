# Learning Objectives

Defined once here. Every other note references `LO-n`.

Neither approved document contains a formal "Tujuan Pembelajaran" list. These objectives are **derived** from the material scope (`Cakupan Materi`), the stage tasks, and the revision's assessment items — each row cites what it was derived from. They are not quoted proposal text, and they are not invented subject matter either.

> Source: Approved Proposal — Section `IDENTITAS BAHAN AJAR` (Cakupan Materi); Approved Revision — Sections `STAGE 1/2/3`; formulation is an Engineering/Instructional derivation

| ID | Objective | Derived from | Stage | Requirements |
| --- | --- | --- | --- | --- |
| **LO-1** | Apply electronics technical-drawing standards: select the correct sheet size, apply standard line thickness, and complete an etiket with a valid scale | Cakupan Materi 1; Scene 02 etiket + scale validation | 1 | REQ-EDU-003, REQ-F-006 |
| **LO-2** | Identify and place IEC/ANSI component symbols with correct orientation and polarity, and build the three specified LED circuits with correct series/parallel topology | Cakupan Materi 3 + 4; Revision §Stage 1 | 1 | REQ-EDU-005, REQ-EDU-009, REQ-F-007 |
| **LO-3** | Explain the function of each manual drawing instrument | Cakupan Materi 2; Scene 01 instrument pop-ups | Guide | REQ-EDU-004, REQ-F-003 |
| **LO-4** | Calculate a copper trace width from load current and copper weight, and apply the etch-safety minimum to signal traces | Revision §Stage 2 | 2 | REQ-EDU-010, REQ-EDU-011 |
| **LO-5** | Route traces between pads following the 45°-corner convention and validate a layout with a DRC | Cakupan Materi 4; Scene 03 | 2 | REQ-F-010, REQ-F-011 |
| **LO-6** | Calculate internal and external casing dimensions from PCB size, standoff height, tallest-component height, clearance and wall thickness | Revision §Stage 3 | 3 | REQ-EDU-012 |
| **LO-7** | Justify dimensional tolerance decisions in manufacturing terms — why a value is chosen, and what fails if it is wrong | Scene 05 reflective quiz; Revision teacher explanations | Closing | REQ-EDU-014 |

## What is *not* an objective

Producing manufacturable output, using real EDA software, soldering or assembly technique. E-DrawLab is explicitly the step *before* the physical workshop (REQ-EDU-018).
