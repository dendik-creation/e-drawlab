# Learning Outcomes

Observable evidence that an objective in [[Learning-Objectives]] was met. Each outcome is something the application can actually witness — that constraint keeps the assessment model honest and testable ([[Educational-Testing]]).

> Source: Approved Proposal — Section `STORYBOARD` Scenes 02–05 (scoring events); Approved Revision — assessment items. Formulation is an instructional derivation.

| ID | Outcome — the learner demonstrably… | Evidence in-app | Objective |
| --- | --- | --- | --- |
| **LOC-1** | Completes an etiket with a scale valid for the sheet size | Etiket validation passes; no scale-error red flash | LO-1 |
| **LOC-2** | Places every symbol of the three LED circuits in a topologically valid position with correct LED polarity | All placements lock; Stage 1 unlocks forward movement | LO-2 |
| **LOC-3** | Distinguishes series from parallel by their drawn appearance, and reads a junction dot as an electrical connection | Correct keys on the topology and node items | LO-2 |
| **LOC-4** | States the function of each manual instrument | Guide instrument pop-ups opened; no in-app scoring specified | LO-3 |

## Attainment reporting

Reported as the per-competency table on Scene 05 plus the "EXPERT CAD DESIGNER" badge (REQ-EDU-016, REQ-EDU-017). The pass threshold for the badge is **not stated** in either document — the storyboard only shows an example result of 92/100 with five stars. Star bands and badge threshold: **To Be Decided**, see [[Assessment-Strategy]] and [[Open-Questions]].
