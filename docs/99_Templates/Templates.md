# Templates

Core-plugin Templates folder (configured in `.obsidian/templates.json`).

| Template | Use for |
| --- | --- |
| [[Feature-Template]] | A new capability note in [[Features]] |
| [[Lesson-Template]] | A new stage or lesson content note |
| [[Research-Template]] | A research note answering one concrete question — [[Research]] |
| [[ADR-Template]] | A new architecture decision — [[Decisions-Index]] |
| [[Meeting-Template]] | A working session that produced decisions or questions |

## Conventions every note follows

1. **Source line.** Every factual claim carries `Approved Proposal`, `Approved Revision`, `Project Brief`, or `Engineering Decision`.
2. **No duplicated requirements.** Cite `REQ-` IDs from [[Requirements-Matrix]] instead of restating text.
3. **Undecided is written, not guessed.** Use a `Status: To Be Decided` block and add the question to [[Open-Questions]] with an owner.
4. **Link, don't copy.** One home per fact; everything else links to it.
5. **No sensitive data.** No credentials, tokens or personal data anywhere in this vault.

Vault entry point: [[Overview]].
